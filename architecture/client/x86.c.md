# client/x86.c

## File Purpose
Implements x86-specific CPU cycle-counting profiling utilities using the RDTSC instruction (opcode `0F 31h`). Provides a histogram-based timing mechanism to measure and record execution durations in CPU cycles, compiled only when targeting x86 (`id386`).

## Core Responsibilities
- Initialize a cycle-count histogram with bias calibration
- Start a cycle timer using RDTSC
- Stop the timer and bin the elapsed cycle count into a histogram array
- Expose the histogram buffer for external consumers

## Key Types / Data Structures
None.

## Global / File-Static State
| Name | Type | Scope | Purpose |
|---|---|---|---|
| `bias` | `static unsigned long` | static | Minimum RDTSC overhead (calibrated at init); subtracted from each measurement. **Note: declared twice — likely a latent bug.** |
| `histogram` | `static unsigned long *` | static | Heap-allocated array of `range` cycle-count buckets |
| `start` | `static unsigned long` | static | RDTSC value captured at timer start |
| `range` | `static unsigned long` | static | Number of histogram buckets / max measurable cycle count |

## Key Functions

### x86_TimerInit
- **Signature:** `void x86_TimerInit( unsigned long smallest, unsigned length )`
- **Purpose:** Calibrates the RDTSC measurement bias and allocates the histogram buffer.
- **Inputs:** `smallest` — offset added to calibrated bias; `length` — number of histogram buckets.
- **Outputs/Return:** None.
- **Side effects:** Sets `range`, `bias`, allocates `histogram` via `Z_Malloc`.
- **Calls:** `x86_TimerStart`, `x86_TimerStopBias`, `Z_Malloc`
- **Notes:** Runs 100 back-to-back start/stop cycles and takes the minimum elapsed count as the raw RDTSC overhead, then adds `smallest` to get the final bias. Only the low 32 bits of RDTSC are used (EAX only; EDX ignored — wraps after ~4 billion cycles).

### x86_TimerStart
- **Signature:** `void x86_TimerStart( void )` (`__declspec(naked)`)
- **Purpose:** Captures the current RDTSC value into `start`.
- **Inputs:** None.
- **Outputs/Return:** None (writes `start` global).
- **Side effects:** Writes `start`.
- **Calls:** Nothing (inline RDTSC via raw opcodes).
- **Notes:** Uses raw opcode emission (`_emit 0Fh / 31h`) for RDTSC, compatible with MSVC assembler syntax.

### x86_TimerStop
- **Signature:** `void x86_TimerStop( void )` (`__declspec(naked)`)
- **Purpose:** Reads RDTSC, computes elapsed cycles minus bias, and increments the corresponding histogram bucket.
- **Inputs:** None (reads `start`, `bias`, `range`, `histogram` globals).
- **Outputs/Return:** None.
- **Side effects:** Increments one `histogram[elapsed]` bucket; discards sample if elapsed is negative (underflow) or `>= range`.
- **Calls:** Nothing.
- **Notes:** The `js discard` guard handles the case where bias overestimates (result would go negative in unsigned arithmetic, caught via signed jump).

### x86_TimerGetHistogram
- **Signature:** `unsigned long *x86_TimerGetHistogram( void )`
- **Purpose:** Returns the pointer to the histogram array for external inspection.
- **Inputs:** None.
- **Outputs/Return:** `histogram` pointer.
- **Side effects:** None.

**Notes:** `x86_TimerStopBias` is an internal helper used only during `x86_TimerInit` calibration; it returns raw elapsed ticks without histogram binning.

## Control Flow Notes
This file is a standalone profiling utility. It is not wired into the main game loop or render pipeline by this file alone; callers invoke `x86_TimerInit` once, bracket code sections with `x86_TimerStart`/`x86_TimerStop`, then read the histogram via `x86_TimerGetHistogram`. The entire file is conditionally compiled under `#if id386`.

## External Dependencies
- `<stdlib.h>` — included but not directly used here
- `"client.h"` — pulls in `Z_Malloc` and the `id386` platform define
- `Z_Malloc` — defined in the engine zone memory allocator (not in this file)
