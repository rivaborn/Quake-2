# game/m_chick.h

## File Purpose
Auto-generated header defining integer frame index constants for the Chick monster's skeletal animation sequences. It maps human-readable animation frame names to sequential integer indices used by the engine's model animation system.

## Core Responsibilities
- Provide compile-time integer constants for every animation frame of the Chick (internally "bitch") monster model
- Cover all animation states: attack, death, duck, pain, stand, walk, and reload/recline sequences
- Define the model scale constant used when rendering this monster
- Serve as the sole source of frame numbering truth for `game/m_chick.c`

## Key Types / Data Structures
None.

## Global / File-Static State
None.

## Key Functions
None. This is a pure `#define` header with no functions, types, or variables.

## Control Flow Notes
This file participates in the animation subsystem indirectly. `game/m_chick.c` includes this header and references these constants when building `mmove_t` animation tables (frame start/end indices). The engine ticks through frame ranges each game frame via the monster AI think functions; the constants here are the terminal values for those ranges.

The animation sequences and their index ranges are:

| Sequence group | Frame range (indices) |
|---|---|
| `attak1` (attack 1) | 0–31 |
| `attak2` (attack 2) | 32–47 |
| `death1` | 48–59 |
| `death2` | 60–82 |
| `duck` | 83–89 |
| `pain1` | 90–94 |
| `pain2` | 95–99 |
| `pain3` | 100–120 |
| `stand1` | 121–150 |
| `stand2` | 151–180 |
| `walk` | 181–207 |
| `recln2` (reload/recline 2) | 208–247 |
| `recln1` (reload/recline 1) | 248–287 |

Total frames: 288 (indices 0–287).
