# game/m_brain.h

## File Purpose
Auto-generated header defining animation frame index constants for the Brain monster model in Quake 2. It maps symbolic frame names to sequential integer indices used by the animation system to index into the model's frame array.

## Core Responsibilities
- Defines all animation frame constants for the Brain monster (`FRAME_*` macros)
- Enumerates frames across all animation sequences: walk, attack, pain, death, duck, defense, and stand
- Provides the model scale constant used when rendering or collision-sizing the Brain entity

None.

## Key Functions
None. This file is a pure preprocessor constant header with no functions or variables.

## Control Flow Notes
This file participates in the animation pipeline passively. `game/m_brain.c` includes this header and uses the `FRAME_*` constants to define `mmove_t` animation sequence structs (frame ranges, callbacks). Those structs are then assigned to `self->monsterinfo.currentmove` during AI state transitions (walk, attack, pain, death), driving per-frame model animation on each server tick.
