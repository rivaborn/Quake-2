# game/m_soldier.h

## File Purpose
Auto-generated header defining all animation frame index constants for the Soldier monster model. It maps symbolic frame names to sequential integer indices used by the animation system in `game/m_soldier.c`.

## Core Responsibilities
- Enumerate every animation frame for the Soldier monster as preprocessor constants
- Provide a `MODEL_SCALE` constant for world-space sizing of the model
- Serve as the sole bridge between the 3D model's frame data and the game logic that drives animations

## Key Types / Data Structures
None.

## Global / File-Static State
None.

## Key Functions
None. This file contains only `#define` preprocessor constants.

## Control Flow Notes
This file has no runtime presence. It is `#include`d by `game/m_soldier.c`, which references the frame constants when constructing `mmove_t` animation sequences (e.g., stand, walk, run, attack, pain, duck, death). The animation system advances `s.frame` through these index ranges each server frame tick.

## External Dependencies
- No includes.
- No external symbols.

## Notes
- Generated by **ModelGen**; not intended for manual editing.
- Frame groups and their ranges:
  | Group | Approx. range | Variants |
  |---|---|---|
  | `attak1–4` | 0–44 | 4 attack sequences |
  | `duck` | 45–49 | 1 duck sequence (5 frames) |
  | `pain1–4` | 50–96 | 4 pain sequences |
  | `run` / `runs` / `runt` | 97–145 | Normal, strafe, turning run |
  | `stand1` / `stand3` | 146–214 | Two idle sequences (30 frames each) |
  | `walk1` / `walk2` | 215–271 | Two walk cycles |
  | `death1–6` | 272–474 | 6 death sequences (largest block, 203 frames total) |
- `MODEL_SCALE 1.2` scales the model uniformly from MD2 model space to game world units.
- The unusually large death block (6 sequences, up to 53 frames each) gives the Soldier one of the highest total frame counts among Quake 2 monsters.
